# Autoresearch: longer multi-step workload for compaction testing

## Objective

Complete all tasks below. Work through them in order.

## Tasks

1. List all files in the current directory.
2. Read article.md and write a 2-sentence summary to summary.md.
3. Read data.json and extract the "avg_length" field. Write it to stats.txt.
4. Read notes.txt and list all TODO items. Write them to todos.txt, one per line.
5. Read script.py and write the function names to functions.txt, one per line.
6. Search for the word "pangram" across all files. Write the file names that contain it to search-results.txt.
7. Create a file called report.md containing: the summary from summary.md, the stats from stats.txt, the TODO count, and the function count.
8. Verify all output files exist and are non-empty.
