## Mechanisms
1. **Economy direction matters**: reporting terseness (words ABOUT work) is safe (the
   terseness campaign's win); process terseness (steps IN the work) skips discovery and
   verification terms. ce-lite's loop is mostly process text — hence this negative result.
2. **Canary reliability beats metric deltas**: baseline had zero failures across every
   run of the week; every economy variant failed somewhere within two runs.
3. **Methodology note — cache-warming drift**: identical-content runs drift downward
   (135.9K→111.5K across the day) as provider cache warms. Same-day keep/discard
   comparisons remain valid (all iterations share the curve), but cross-day numbers need
   a fresh baseline each session.
4. **Canary calibration is real work**: quote styles (`cfg['x']` vs `cfg["x"]`), valid
   clone idioms (`JSON.parse(JSON.stringify)`), and handoff phrasing all produced false
   failures before calibration; the s5 model-note check now accepts semantic equivalents.
